
# Auto-Get URLs Script

## Descrizione

Questo Script nasce molto tempo fa da un'esigenza.  
Mi capitava spesso di avere troppe schede aperte contemporaneamente nel browser, e prima di chiuderle, mi serviva ottenere l'indirizzo URL di ogni signola scheda e spesso capitava che erano decine o più di 100.

Quindi ho risolto il problema creando questo Script, cominciando a sperimentare con l'automazione attraverso la Libreria "pyautogui" unita alla Libreria "pyperclip" per copiare le stringhe degli indirizzi negli appunti ed infine col modulo "time" per gestire i margini di tempo e prevenire problemi derivati dalla troppa velocità tra un processo e un altro.

Il risultato finale riposto negli appunti, lo copio in un file .txt per salvare il tutto.

In parte sviluppato con IA.
